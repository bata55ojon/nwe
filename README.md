# HOT CONTENT SHOP

Crie um site completo, moderno e premium para uma loja de produtos digitais chamada HotShop.



O site deve ser totalmente responsivo e ter como prioridade uma excelente experiência em dispositivos móveis.



IDENTIDADE VISUAL



A identidade visual deve ser baseada em PRETO + VERMELHO.



- Fundo principal: preto ou preto muito escuro.

- Cor de destaque principal: vermelho.

- Texto principal: branco.

- Texto secundário: cinza claro.

- Cards: preto/cinza muito escuro.

- Bordas e detalhes: vermelho sutil.

- Botões principais: vermelho.

- Efeitos de glow e hover em vermelho.

- Gradientes discretos usando tons de vermelho.

- Não usar azul, roxo ou verde como cores principais.

- Visual premium, moderno, elegante e chamativo.

- Usar bordas arredondadas e glassmorphism de forma moderada.

- Animações suaves e profissionais.

12. RESPONSIVIDADE



O site deve ser desenvolvido primeiro pensando em celulares.



No mobile:



- Cards ocupam a largura adequada.

- Vídeos não ultrapassam a tela.

- Botões são grandes e fáceis de tocar.

- Header transforma-se em menu hambúrguer.

- Textos ficam perfeitamente legíveis.

- Notificações ficam adaptadas à largura da tela.

- Checkout funciona perfeitamente em telas pequenas.



No desktop, aproveitar melhor o espaço e apresentar os produtos em uma grade de várias colunas.

16. IMPORTANTE





Não fingir que um pagamento foi concluído.



Não criar um sistema falso de confirmação de pagamento.



O site deve apenas apresentar os produtos, permitir que o cliente escolha o método de pagamento e encaminhá-lo para o Telegram para finalizar a compra.



Criar o projeto completo e funcional, com 25 produtos, interface premium preto e vermelho, duas prévias de vídeo por produto e fluxo completo até o Telegram.



O resultado final deve parecer uma loja digital premium profissional, e não um template básico.
